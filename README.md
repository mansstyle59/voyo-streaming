# VOYO — Films, séries et TV

Prototype web responsive pour explorer une interface de streaming VOYO.

## Démo locale
Ouvrir `index.html` dans un navigateur.

## Publication GitHub Pages
Le workflow `.github/workflows/deploy.yml` publie automatiquement le site à chaque push sur `main`. Dans GitHub, ouvrir **Settings → Pages** et sélectionner **GitHub Actions** comme source si ce n'est pas déjà configuré.

## À savoir
- Le catalogue actuel est constitué de données de démonstration, sans lecture vidéo ni flux TV connectés.
- N'ajouter que des flux et contenus que vous êtes autorisé à diffuser.
- Le dépôt est indépendant des autres projets.
